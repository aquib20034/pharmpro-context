MVP screens — HTML wireframes

Static mockups of the main MVP screens from docs/01-mvp-scope.md. Compact by design: 13px base, 28px controls, 30px table rows. Interactions (tabs, modals, drawers, POS cart and payment math, command palette Ctrl K) are simulated client-side so flows can be clicked through. No backend.

Design languageInk sidebar · Teal primary · Indigo secondary · Warn · Danger. Inter + JetBrains Mono for numbers/codes.
Density rulesSmall controls (28px), dense tables, hover row actions, inline edit cells in document grids, sticky headers, totals rows, URL-synced filter chips. No large buttons or hero forms.
Expiry heatexpired ≤30d ≤90d ok — the same tokens are used on every screen that shows a batch.
